# التجويد الميسر — روابط QR

موقع روابط وسيطة للرموز المطبوعة في الكتيب.

## تعديل وجهة أي رمز
افتح ملف `links.json` وعدّل قيمة `url` للحكم المطلوب، ثم احفظ التعديل (Commit). سيستمر رمز QR القديم في العمل ما دام عنوان الموقع ومسار `go.html?rule=...` ثابتين.

**مهم:** الروابط المدرجة مبدئية، وتحتاج مراجعة موضع الحكم القرآني قبل طباعة الكتيب. لا تغيّر أسماء المفاتيح الإنجليزية بعد توليد الرموز.

## النشر
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

المستودع يجب أن يكون مؤهلًا لـ GitHub Pages وفق الخطة والخصوصية. عند استخدام GitHub Free اجعله عامًا من Settings → General → Danger Zone → Change repository visibility.

## ملاحظة
لا تتضمن الصفحات ملفات صوتية؛ التحويل إلى Quran.com حيث يمكن الاستماع إلى الآيات.
